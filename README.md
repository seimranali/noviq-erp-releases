# Noviq ERP — Releases

Downloads for **Noviq ERP**, the business management system by **Noviq Technologies**: accounting, sales, purchases, inventory, payroll and distribution in one app.

## Download

Get the latest version from the **[Releases](../../releases/latest)** page.

| File | For |
|---|---|
| `ricebiz-server-<version>-windows.zip` | Windows server: web app, API, and setup scripts (Windows service or IIS) |

## Install on Windows

1. Install **Node.js 20+** and **Microsoft SQL Server** (Express is fine).
2. Extract the zip, for example to `C:\NoviqERP`.
3. Open PowerShell **as Administrator** in the extracted folder and run:
   ```powershell
   .\windows\install-windows.ps1
   ```
4. Open the app in a browser and sign in. A licence key is required; contact Noviq Technologies with the Machine ID shown under Settings → License.
